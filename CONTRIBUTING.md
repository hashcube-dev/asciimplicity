# Contributing Guidelines

## Making a Manifest

Making a manifest is simplified by the `./create` script. The script requires nushell to run.
Simply follow the instructions and then make the art.

Symlinks are allowed to help shorten the names of otherwise long games.
Symlinks can also be used when a game is only available on one platform

Ex: `dale_&_dawson_stationery_supplies-steam.yaml` -> `dale_&_dawson_stationery_supplies.yaml` -> `ddss.yaml`

## Submitting a Manifest

Please submit your manifest as a PR on either
[Tangled](https://tangled.org/hashcube.dev/asciimplicity/pulls/new) or [GitHub](https://github.com/hashcube-dev/asciimplicity/compare).
Please also ensure your manifest builds correctly and all of the info is correct.

## Software/Games Rules

I will not be creating or accepting any grids for software created by a person or group of people who are
transphobic, homophobic, racist, sexist, or otherwise bigoted in some way.

## Playstyle Indicator

The Playstyle Indicator are three bullet points colored in green if that playstyle is available,
and red if it is not available.

### Requirements for Single-Player

In order for a game to be considered having "Single-Player" it must follow the
following criteria:

1. The game is fully functional with only one player
2. The game is not significantly hindered by playing with one player

A game like Celeste is considered to have "Single-Player" whereas
Dale & Dawson Stationery Supplies is NOT considered to have "Single-Player" because the
game is significantly hindered by playing with only one player.

### Requirements for Online Multiplayer

In order for a game to be considered having "Online Multiplayer" it must follow the
following criteria:

1. The game is able to be played with multiple people without modification (mods, cheats, ...) across the internet

A game like Overwatch is considered to have "Online Multiplayer" whereas
Super Mario Odyssey is NOT considered to have "Online Multiplayer," as this functionality is part of a mod.

### Requirements for Local Multiplayer

In order for a game to be considered having "Local Multiplayer" it must follow one of the
following criteria:

1. The game is able to be played with multiple people in the same room without modification (mods, cheats, ...)
2. The game is able to be played with multiple people without a connection to the internet without modification (mods, cheats, ...)

A game like The Jackbox Party Pack is considered to have "Local Multiplayer" because it fulfils requirement 1.
A game like Minecraft is also considered to have "Local Multiplayer" because it fulfils requirement 2.
A game like Ultimate Chicken Horse is also considered to have "Local Multiplayer" because it fulfils both requirements.
